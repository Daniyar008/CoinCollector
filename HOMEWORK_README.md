# Домашняя работа, модуль 4

Открывайте Assets/Scenes/MainMenu.unity и нажмите Play → «Ойнау».

Выполнено:
- HealthSlider: 0–100, целые значения, управление мышью выключено. При уроне обновляются и текст, и зелёная полоса.
- WinPanel: после пяти монет появляется «Жеңіс!», время останавливается. Кнопки перезапуска и меню восстанавливают Time.timeScale = 1.
- CoinPulse.anim: цикл длиной 1 секунда, 60 кадров/сек. Ключи масштаба X/Y: 1 → 1.3 → 1 в моменты 0 → 0.5 → 1 секунда. Z = 1. Loop Time включён. Анимация назначена CoinVisual в префабе Coin через Animator; все пять монет наследуют её. Родитель сохраняет прежний масштаб 0.55, чтобы монеты остались того же размера, а коллайдер не пульсировал.
- Дополнительно: Esc включает/выключает паузу. Есть кнопки «Жалғастыру» и «Мәзір». Пауза не отменяет победу или Game Over.

Управление: A/D или стрелки — движение; Space — прыжок; Esc — пауза; R — перезапуск во время игры.

Код:
- Player.cs — healthSlider.value, проверка Score >= totalCoins, блокировка управления после конца игры.
- PauseManager.cs — переключение панели и Time.timeScale.
- MenuManager.cs — переходы между сценами и перезапуск.
- Spawner.cs — цикл, создающий пять монет из префаба.

Для просмотра анимации откройте Assets/Prefabs/Coin.prefab, выберите CoinVisual, затем Window → Animation → Animation. Файл клипа находится в Assets/Animations/CoinPulse.anim.

В папке Homework_Screenshots рядом с проектом находятся три снимка для сдачи: игровой процесс, победа и главное меню. Вчерашняя версия сохранена отдельно в CoinCollector_Yesterday.zip.
