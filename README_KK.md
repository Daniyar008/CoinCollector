# Практикалық жұмыс — Тиын жинаушы

Unity нұсқасы: 6000.0.83f1 (Unity 6).

1. Unity Hub → Add → Add project from disk арқылы осы CoinCollector бумасын таңдаңыз.
2. 4-модуль үшін Assets/Scenes/MainMenu.unity сахнасын ашыңыз. Ойын сахнасы — Game.unity. Бұрынғы CoinCollector.unity сақталған.
3. Play басып, «Ойнау» батырмасын басыңыз. Толық түсіндірме MODULE4_KK.md файлында.

Басқару: A/D немесе ←/→ — жүру; Space — секіру; R — қайта бастау.

Көк Player нысанында Box Collider 2D, Rigidbody 2D және Player скрипті бар. Айналу бұғатталған. Ground нысанының тегі — Ground, қызыл Spike нысанының тегі — Enemy. Coin префабында Circle Collider 2D және Is Trigger қосылған, тегі — Coin.

Қосымша тапсырма орындалған: Spawner скрипті Coin префабынан бес тиынды іске қосылғанда жасайды. Сондықтан редакторда Play басылмай тұрғанда тиындар көрінбейді.

Тиынға тигенде ол жоғалады және Console ішінде «Ұпай» артады. Қызыл кедергіге әр қайта тигенде өмір 20-ға азаяды. Ұпай мен өмір Game экранында да көрсетіледі. Ауада екінші рет секіруге болмайды.

PDF үлгісімен салыстырғандағы жақсартулар: қозғалыс Rigidbody2D арқылы FixedUpdate ішінде орындалады; жерде тұру төменгі жанасу арқылы тексеріледі; өмір нөлден төмен түспейді. Ескі Input Manager қосылған.

Негізгі код: Assets/Scripts/Player.cs және Assets/Scripts/Spawner.cs.
Assets/Editor және PracticeVerification.cs — жобаны дайындау және автоматты тексеру көмекшілері; қалыпты ойнағанда тексеру іске қосылмайды.
