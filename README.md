# CoinCollector — Unity, 5-модуль

Үш деңгейден тұратын 2D платформер. Барлық тиынды жинап, уақыт рекордын жаңартыңыз.

**Ашу:** Unity Hub → Add project from disk → осы папка.
Unity нұсқасы: **6000.6.0f1**. `Assets/Scenes/MainMenu.unity` сахнасын ашыңыз.

**Басқару:** A/D немесе ←/→ — жүру, Space — секіру, Esc — пауза, R — қайта бастау.

Сахналар: MainMenu → Game (5 тиын) → Level2 (8 тиын) → Level3 (10 тиын).
Жеңіс панелінде уақыт пен рекорд, мәзірде бірінші деңгейдің рекорды көрсетіледі.

[Кодтың қазақша түсіндірмесі](MODULE5_KK.md)

Windows нұсқасын құрастыру: File → Build Profiles → Windows → Build.
Assets/Editor/Module5Builder.cs тапсырма сахналарын және Windows нұсқасын
қайта жасауға арналған. Деңгейді қолмен өзгерткеннен кейін бұл генераторды
қайта шақырсаңыз, оның бастапқы орналасуы қайта жасалады; әдетте жай Build қолданыңыз.

Тексеру режимі: құрастырылған ойынға `--verify-module5` аргументін беріңіз.
Ол тексеру скриншоттары мен есебін ойын папкасының жанындағы
Module5_Verification қалтасына сақтайды және ойыннан шығады.
Тексеру рекордтардың алдыңғы мәндерін аяқталған кезде қалпына келтіреді.

Қажетсіз AI Assistant / Inference және Multiplayer Center пакеттері
ойын құрастыруын жеңілдету үшін алынды. Бұл ойын олардың API-лерін қолданбайды.
